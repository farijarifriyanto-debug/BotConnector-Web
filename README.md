# BotConnector Web

Situs marketing dan dokumentasi BotConnector — sumber dari [botconnector.id](https://botconnector.id/).

Marketing site and documentation for BotConnector — the source behind [botconnector.id](https://botconnector.id/).

## Isi / Contents

- **Marketing pages** (ID & EN): beranda, harga, model, halaman produk — `src/content/`
- **Docs**: panduan AI Cloud, API reference, integrasi, tips — `src/content/docs/` via Astro Starlight

## Pengembangan / Development

```bash
npm install
npm run dev      # dev server lokal
npm run build    # build produksi
npm run preview  # pratinjau hasil build
```

Butuh Node.js 22.12+.
